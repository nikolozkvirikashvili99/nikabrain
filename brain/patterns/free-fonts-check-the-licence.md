**Rule:** before using a font a user found on a free-font site, read its
licence. "Free" there usually means *free for personal use*, and a
portfolio, shop or client site is commercial use.

**Why:** 2026-11-13, a photographer's portfolio. The requested display font's
page said "Free for personal use · Not free for commercial use … a demo
version". Stopped before downloading; the user chose a free look-alike.
Also: judge the look from the font's own preview image, not its name or
category. The first look-alike round compared scripts, but the font was a
1970s display serif, so the comparison had to be redone.

**How to apply:**
- Fetch the font page; quote the licence line; name the paid-licence link.
- Offer: (1) an OFL look-alike (Google Fonts, loads like the other fonts),
  (2) buy the licence incl. webfont use, (3) local preview only, never pushed.
- Compare candidates rendered with the real text on the real background.

**Signal:** a link to dafont / 1001fonts / fontspace / similar.
