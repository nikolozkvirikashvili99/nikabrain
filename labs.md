# Projects connected to nikabrain

`/onboard-project` adds a row. Kinds: **own** (your projects; memory may live
in `nikabrain/memory/<name>`), **lab** (learning repos, `/tutor` mode),
**work** (employer or client: memory stays local, never in nikabrain).

| Project | Path | Kind | Purpose | Memory |
|---|---|---|---|---|
| nikabrain | `~/projects/nikabrain` | own | this brain | `brain/`, `me/` |
